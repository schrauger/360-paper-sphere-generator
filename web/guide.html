Print

Print the PDF at 100% ("Actual size", not "Fit to page") on cardstock or photo paper. Scaling moves the pieces and the cutter marks.

Cut outline

The thin printed line around each piece is a guide for cutting by hand with scissors or a craft knife.

With a cutting machine you don't need it. Turn Cut outline off: the machine cuts from the cut file, and a printed line can show at the edge if the cut is a hair off.

Cutting machine: Silhouette, SVG cut file

Silhouette Studio opens SVG files only in Designer Edition or higher (Designer, Designer Plus, Business). The free Basic Edition can't open SVG, but it opens the DXF cut file and .studio3 files.

  1. In the app, set Cutter marks to Silhouette and Cut file download to SVG.
  2. Download the sheet (the PDF) and the SVG cut file.
  3. Print the PDF at 100% (Actual size).
  4. Open the SVG in Silhouette Studio.
  5. Select all the SVG objects and Group them.
  6. In the Transform panel, set the group's position to X 10 mm and Y 10 mm.
  7. Turn on registration marks and set the inset to 10 mm (in the page setup / registration marks settings).
  8. Load the printed sheet into the machine and cut.

Silhouette .studio3 files

For Letter paper, the listed sphere sizes and "As many as fit", choose .studio3 (Silhouette) as the cut file. The app sets the cutter marks and sphere count for you and flags any setting that doesn't fit. Open the file in Silhouette Studio, load the printed sheet and cut. No positioning is needed. The files are being added size by size; until a size has one, the app says so and you can use the SVG cut file instead.

Ties and DXF

Ties are optional small bridges that keep the tabs attached on the mat, so you can pop the pieces out afterwards. DXF is the cut file for programs that don't read SVG, including Silhouette Studio Basic Edition.
